`StudioCanvas`为全屏淡绿渐变与宽弧带；代码绘制的是背景，不可拿这条例外去重画应用图标。页面铺满窗口，白色/半透明卡片不过重，个人简介不要再叠一块突兀的旧背景。Live/Shorts媒体背景保留黑色柔和上下渐变提高白字可读性。

`TetoRhythm-Text.ttf`与`TetoRhythm-Display.ttf`：正文/艺术标题，UIFontMetrics适配Dynamic Type。不是换成纯系统标题；已修正字形6和8混淆，复用包内字体不要恢复旧版本。字体实际文件及Info.plist注册保持一致，不依赖机器装字体。

`TetoIcon`加载透明PNG（搜索环中间透明、青柠柄；独立听筒/挂断图标等）。禁止应用按钮退回SF Symbols、Emoji或手写路径图标。源码里的旧symbol字符串只作兼容字段，必须核对它没走到系统图标渲染。系统照片选择器、分享面板、键盘图标不受替换范围约束。

当前用户Logo为青柠方形Teto字标原图，保留原色和图案；AppIcon1024×1024无透明，TetoMark/Wordmark按原色绘制不tint。欢迎标识112pt、loading160pt，view层圆角，不修改原图。新生成图标可参考同套Fresh Studio，Logo未经新要求不重绘。双人练舞插画用于Welcome/协议页；不能把整张历史截图作为页面背景再叠UI。

基础控件≥44×44pt热区，卡片通常16–24pt圆角；52pt浮动Create；dock66pt高、外侧16pt、底安全区以上6pt、圆角30；滑动选中气泡按4等分计算，不能只删第五个按钮但留下width/5和index上限4。影片之外的按钮保持安全区，不把截图像素当point。

搜索/Live-Shorts/Voice分类采用气泡或展开交互，遵守Reduce Motion。长昵称不挤掉关闭/Send，长句动态多行；横屏右侧动作rail可滚动。未知头像/空群用已有图标，不借用其它人物照片。

## 资源包范围

附带39组Live/Shorts舞蹈视频和对应JPG封面，来源为原项目已登记、历史代表帧审查过的Pexels舞蹈素材。完整精确列表见 `media-inventory.md` 和模板内 `Design/SourceMedia/manifest.json`。七段Phrases教学影片不在模板或运行时catalog里；不是藏在Design归档。

真人头像、房间封面、生活化图用于社交上下文：可有练习、休息、鞋子等照片，但不能把非舞蹈**视频**伪装成Live/Shorts影片。照片中的人不自动成为实名账号、片源作者或平台用户。保留真实摄影署名；作者未核实的记录保持null，不补写。

不同人物不同头像，同一人物跨页面一致；群聊最多9位成员拼图；房间成员ID跨内置房间不重复。头像、封面、视频不能靠复制改文件名凑数量。源项目2026-10-23曾检查46段代表帧及资源唯一性；本模板仅沿用该证据和39条子集，不宣称本次重新逐帧人工看完。

运行时视频是已压缩HEVC/hvc1，保持原尺寸、帧数、时间戳、音轨和播放速度；图片压缩不改受保护Logo/Icon解码像素。不得报告全项目原192MB为本模板大小，也不能把资源字节量称为IPA尺寸。模板manifest给出本包实际字节数。

## 替换/扩充规则

1. 拿到可用真实视频，检查多个代表时间点实际有人跳舞（开始/中间/结尾及较长片的中间段），检查画面字幕、水印、贴纸英语与禁用文案。静态封面不能替代视频检查。
2. 记录作者、source URL、download、license名称与链接、原始文件哈希/路径、运行时映射/哈希、裁切转码情况、抽帧检查点；YouTube/TikTok平台名称不代表一概可再分发。
3. 保持比例和原速度。填满屏幕使用等比裁切，不能拉伸或加速原片。生成与原片匹配且独立的封面。
4. 在DanceVideoCatalog分配稳定UUID和surface，维护新collectionGeneration；全引用、source登记、catalog与资源一一对应。不是复制同片到Live/Shorts两个ID。
5. 删除不合格的**项目提供素材**时包括运行时、原片、封面、工程引用；私人设备内容仅过滤/分类或用户显式删除。来源和删除记录可保留。
6. 模板只携带运行时资源与来源记录；原始Design视频仍在原Teto项目，`originalPath`不是模板内存在声明。完整原片不是运行依赖，若重新处理需从合法来源/原项目取得。
