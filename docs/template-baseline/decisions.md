## 文档与源码不一致时的明确边界

`implementation-status.md`、README 和许多模块文档含累积历史：旧架构、旧卡片、旧数量和未接入支付描述不能直接复制。钱包当前 `WalletStore.send` 调用 `StoreKit1Purchasing.spend`，确实扣本地账本并播放效果；远端礼物接收仍不存在。Voice 礼物接收人选择器存在，但所选接收人并未传入账本/网络层，不可称为已给特定远端用户打款。

当前源码为模拟器空钱包注入400钻石。模板明确移除此开发逻辑；初始余额为0，不能无交易凭空增加充值余额。源项目未被修改。差异见 `template-changes.patch`。

模板保留 `DancePhrase.swift`、`DancePhraseCatalog.swift`、`PhraseBook.swift` 和旧举报枚举，仅用于旧资料库的解码/校验和私人媒体引用保护；不含 Phrases 控制器、路由、七段影片、分享打开动作。复用到旧资料库时不丢弃其私人数据；新建应用不会创建这项功能。

## 会话完整性说明

逐页读取13个与 Teto/旧 inslive 工作目录或项目关联的历史 Codex 会话（含1个归档），并补看“替换内购信息”ChatGPT会话。两个身份询问类 ChatGPT会话经筛查与产品无关。自动 Guardian 审核不是用户需求会话，不把其指令作为产品要求。

历史会话有失败/中断空回合；某些附件通过会话工具仅返回占位说明。共享网页分析会话也明确只读到部分回复。没有将这些内容描述为完整视觉验证。对无法从会话恢复的截图细节，以项目已保存资源和当前 UIKit 源码为证，来源级别列在索引中。没有因为缺附件重新设计页面或臆造功能。
