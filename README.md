## Source-media protection

All source images, videos, fonts and verification screenshots stay in the ignored root `Assets/` archive. Build caches and test bundles are excluded separately. Application media is acquired from the pinned HTTPS resource manifest; agreement HTML remains in `Agreements/` as documented there. Local verification screenshots newly moved into Assets are not runtime inputs and have not been uploaded to R2.

The pre-push hook scans every historical tree and blob reachable from the refs being pushed. It rejects Assets paths, media filenames/signatures and files larger than 5 MiB, including files removed from the latest commit. This workspace enables the hook with `core.hooksPath=.githooks`. After cloning, enable it with `git config core.hooksPath .githooks`. To inspect every local ref, run `python3 TotiMusic/scripts/check_git_media.py --all`.

Keep the manifests, resource scripts and `.githooks/` in commits. Local source-code changes still require a normal commit before they are included in a push. The external history backup is outside this repository and must not be copied into it.
